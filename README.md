The goal of the project is a desktop app that luthiers can use for common calculations.

Currently it's an HTML program that I started a while ago but it may be that HTML is absolutely wrong for this.  It's entirely vibe coded on Claude so far.

Current functions
1) Nut and saddle compensation for all manners of fretted instruments.  Several formula for doing nut compensation.
2) String spacing for all manner of instruments
3) A unit converter for measurements, also this is a place where you can store measurements you use frequently.
4) an IR calculator.  I'm currently working on a new IR calculator that isn't HTML based so this is probably going to die at some point.
5) A drag and drop wiring diagram creator that can wire any sort of pickup/switch/jack combination you desire.  More or less non functional.
